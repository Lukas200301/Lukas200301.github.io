    What it does

    Find out who's on your network, what they're doing with it, and decide how much of it they get.

    Device discovery

    Scan the network and see every device on it, live.

    • Automatic device identification
    • Hostnames and MAC addresses
    • Online status in real time
    • Network topology mapping

    Traffic control

    Decide per device what gets through.

    • Cut or restore internet access
    • Redirect a device's traffic
    • Limit its bandwidth
    • Time-based and group rules

    Packet capture

    Watch what's actually crossing the wire.

    • Real-time packet sniffer
    • Protocol inspection and flow analysis
    • Per-interface monitoring
    • Data usage and performance metrics

    Rule builder

    Set it up once and let NetW1re apply it.

    • Match by MAC, IP or hostname
    • Time-of-day schedules
    • Block, redirect or limit automatically
    • Rule priorities

    Modern interface

    Avalonia UI with ReactiveUI, following MVVM.

    • Customizable themes
    • Real-time notifications
    • Responsive layout

    Cross-platform

    One codebase on .NET 9 for Windows and Linux.

    • Windows, with the Npcap driver
    • Linux
    • Native performance

    How you use it

    Scan, pick a device, act on it. When you find yourself doing the same thing every evening, turn it into a rule.

    1. Scan

      Click Scan to discover the devices on your network.

    2. Control

      Right-click a device to block it, redirect its traffic or limit its bandwidth.

    3. Inspect

      Open the Sniffer tab, pick a network interface and start capturing. Filter as packets arrive.

    4. Automate

      In the Rule builder, match by MAC, IP, hostname or time and choose the action.

    Troubleshooting

    The usual suspects, and what to try first.

    A device doesn't show up

    Discovery only sees devices on your own subnet, and some devices go quiet while they sleep.

    • Make sure the device is on the same network subnet
    • Give the automatic discovery a few minutes
    • Press Refresh to force a new scan
    • Check whether the device is asleep or in power-saving mode
    • Make sure your firewall isn't blocking discovery
    Block, redirect or limit has no effect

    Changing other devices' traffic needs elevated rights and an adapter that can inject packets.

    • Run NetW1re as administrator (Windows) or root (Linux)
    • Check that your network adapter supports packet injection
    • Make sure the target device is still online
    • Close other network management software that might interfere
    • Restart NetW1re if it keeps happening
    High CPU or memory use

    Constant scanning and packet capture are the expensive parts.

    • Scan less often (in the settings)
    • Stop the packet sniffer when you aren't using it
    • Keep the number of active rules down
    • Close other memory-hungry applications
    • Update to the latest version
