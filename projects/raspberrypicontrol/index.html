What it does

Everything you'd normally SSH in for, in one app: watch the system, manage containers and services, update packages, open a shell or move files.

Live dashboard

CPU, memory, temperature and uptime, refreshed every 500 ms.

  • Graphs of the last 60 seconds
  • Memory split into used, free, cached and swap
  • CPU and GPU temperature gauges
  • Top processes, network interfaces and disks

Docker

Every container and its state, with one-tap controls.

  • Start, stop and restart
  • Live log streaming with auto-scroll
  • Image, ports and creation date

Services

Manage systemd services without typing systemctl.

  • Active, inactive and failed at a glance
  • Start, stop and restart
  • Enable or disable at boot
  • Search by name

System updates

See what's out of date and upgrade it from the app.

  • OS, kernel and architecture overview
  • Check for package updates
  • Upgrade one package or everything
  • Upgrade log streamed live

Terminal

A full xterm-256color shell that works on a phone keyboard.

  • Extra keys: Esc, Tab, Ctrl, Alt, arrows
  • Command history
  • Copy and paste
  • Several sessions at once

Files

Browse the Pi's file system over SFTP.

  • Upload and download with progress
  • Previews with syntax highlighting
  • Rename, delete, create folders
  • Change permissions, act on many files

Packages

Search, install and remove packages.

  • Search the repositories
  • Package details and dependencies
  • Install log streamed live

Logs

The systemd journal, streamed live.

  • Filter by level: error, warning, info
  • Filter by service
  • Search with highlighting
  • Export for later

Connections

Keep several Pis one tap apart.

  • Saved connections, stored securely
  • Favorites and connection history
  • Auto-reconnect with retries

How it works

The app talks to a small Go agent on the Pi over gRPC and Protocol Buffers. All of it runs through SSH, so there is nothing to open in your firewall.

The app Flutter on Android or Windows
SSH tunnel
Go agent gRPC on localhost, one ~10 MB binary
reads & controls
Your Pi System stats, Docker, systemd, packages, journal
Sets itself up

On the first connection the app detects the Pi's architecture and installs the agent in about five seconds. After that, connecting is instant, and the agent updates itself when needed.

Nothing exposed

The agent only listens on localhost. Every byte goes through the encrypted SSH tunnel, so no extra ports and no firewall rules.

Private by default

Passwords are kept encrypted in your device's keychain. No telemetry, no data collection.

Runs on Pi Zero / Zero W ARMv6 Pi 2 / 3 ARMv7 Pi 3 / 4 / 5 64-bit ARM64

Get started

Install the app and connect, or build everything yourself from source.

Install the app

Ready-made builds for Android and Windows.

  1. Enable SSH on your PiThe app connects on port 22 with your normal login.
  2. Download the appGet the Android or Windows build from the latest release on GitHub.
  3. Add your Pi and connectEnter its address, user and password. The agent installs itself on the first connection.

Build from source

Generates the protobuf code and cross-compiles the agent for every Pi.

  • Flutter SDK 3.10+, check with flutter doctor
  • Go 1.25+ to build the agent, check with go version
  • Protocol Buffers compiler (protoc) for code generation

Steps

1 · clone
git clone https://github.com/Lukas200301/RaspberryPi-Control.git
cd RaspberryPi-Control
2 · build protobuf + agent binaries (PowerShell)
.\build_all.ps1
# Dart protobuf code   -> lib/generated/
# Go protobuf code     -> agent/proto/
# Agent binaries       -> ARMv6, ARMv7, ARM64
3 · run or build
flutter pub get
flutter run

# release builds
flutter build apk --release
flutter build windows --release
Installing protoc
protoc
# Windows (Chocolatey)
choco install protobuf

# macOS (Homebrew)
brew install protobuf

# Debian / Ubuntu
sudo apt-get install protobuf-compiler

protoc --version
