How to play

  1. Open the terminal with the button above and type ctf. It shows the levels and where to go next.
  2. Go to a level with cd ~/ctf/level1 and read the story with cat README.
  3. Dig. Every level hides a flag that looks like flag{...}. Use the shell's tools: ls -a, ls -l, grep, base64 -d, caesar, xxd -r, git log, stat, and pipes like a | b.
  4. Hand it in with submit flag{...}. The next level unlocks.
  5. Stuck? ctf hint gives a nudge; ask again for a more direct one. ctf reset starts over.
